1. Executive Summary & Status

NVSHOP.LK is a production-grade full-stack e-commerce web application engineered for the official retail showroom in Ambalangoda. The platform provides end-to-end shopping workflows, real-time inventory management, dual-channel OTP security (Email + Sri Lankan Mobile SMS), and order tracking with automated invoices.

2. Technology Stack & Architecture

💻 Frontend Architecture
  • Core Framework: React 18 (Single Page Application)
  • Build Tool: Vite v8.0 (Lightning-fast HMR)
  • Routing: React Router DOM v6
  • State Management: Zustand (Global Stores for Cart, Auth, Wishlist, Compare)
  • Styling: Tailwind CSS & Modern Vanilla CSS
  • Icons: Lucide React Icons
⚙️ Backend Architecture
  • Framework: Spring Boot v4.1.0 / Java 17 LTS
  • Web Server: Embedded Apache Tomcat 11 (Port 8080)
  • Security: Spring Security, BCrypt Hashing, CORS Filter
  • ORM / Data Layer: Spring Data JPA & Hibernate 7
  • Connection Pool: HikariCP (Auto-reconnect, 20s timeout)
  • Validation: Jakarta Validation API
🗄️ Database Management
  • Engine: MySQL (via XAMPP / MariaDB on Port 3306)
  • Database Name: gpsd_project
  • Tables: users, products, orders, order_items
  • Features: Foreign key constraints, indexed searches
☁️ Cloud & External Integrations
  • SMS Gateway: Notify.lk REST API (User ID: 32620)
  • Email Dispatch: Google Gmail SMTP (Port 587 TLS)
  • Maps Platform: Google Maps Showroom Navigation
